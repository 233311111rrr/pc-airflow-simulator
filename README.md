# 🌬️ PC 機殼風流模擬器 (PC Case Airflow Simulator)

在瀏覽器裡模擬電腦機殼內的**風向、風速與溫度分佈**,用來比較正壓、負壓、水冷排與風扇配置的相對差異。

單一 HTML 檔案、**零依賴、不需安裝**,手機、平板、電腦都能用。

> ⚠️ 這是 **2D 側視剖面的簡化流體模擬**,適合做「配置之間的相對比較」,**不是精確的 CFD**。CPU / GPU 溫度為粗略估算。

---

## ✨ 功能

### 模擬與顯示
- 側視剖面(左＝前、右＝後、上、下),溫度熱圖(藍＝室溫 → 紅＝高溫)
- 白色箭頭顯示風向與風速,可切換「溫度 / 風速」顯示
- 即時數據:進風 / 排風 CFM、淨差、**正壓 / 負壓 / 平衡**判定、平均機內氣溫、CPU / GPU 估算溫度
- 模擬畫面固定在頁面上方,下方設定區可獨立捲動

### 機殼與環境
- 自訂機殼深度、高度、厚度(cm)
- 側板:玻璃側透 / 實心鋼板 / 網孔(影響散熱損失)
- 底部電源罩選項
- 室溫、進風濾網堵塞率

### 風扇
- 數量不限,可設定安裝側(前 / 後 / 上 / 下)、位置 %、**12cm / 14cm**、進風 / 排風
- **手動輸入最大風量 (CFM) 與上限 RPM**,轉速可用滑桿(0–100%)或直接輸入 RPM
- 內建預設配置:正壓、負壓、平衡、水冷範例

### CPU / GPU
- 位置與大小可**在畫面上直接拖曳**,或輸入左 / 上 / 寬 / 高(%)
- 氣冷或水冷,可設定負載 %
- 顯卡可自訂**風扇數量、口徑、單顆 CFM、上限 RPM、轉速**,顯卡溫度估算會隨風扇風量變化
- **型號資料庫**:選擇後自動套用瓦數、尺寸與風扇資料
  - 顯卡:NVIDIA RTX 50 / 40 / 30 / 20 與 GTX、AMD RX 9000 / 7000 / 6000 / 5000、Intel Arc
  - CPU:Intel Core Ultra 200S、12–14 代、AMD Ryzen 5000 / 7000 / 9000、Threadripper
  - 散熱器:常見氣冷塔式與 AIO 水冷頭尺寸

### 水冷
- 水冷排(120 / 140 / 240 / 280 / 360 / 420)可指定安裝側、位置、厚度與負責冷卻的對象(CPU / GPU / 兩者)
- 水冷元件的熱量 **100% 由水排散出**,氣流穿過水排時會受到阻力並被加熱
- 水冷元件沒有指派水排時,會自動退回氣冷

### 其他
- **被動開孔**(濾網 / 網孔)
- **溫度計**:數量不限,可拖曳或輸入位置,讀數為該點周圍空氣溫度
- RWD 版面:自動適配不同螢幕大小,支援深色 / 淺色模式與觸控操作

## 🎮 操作說明

| 操作 | 方式 |
|---|---|
| 移動 CPU / GPU / 溫度計 | 在畫面上直接拖曳,或在對應分頁輸入位置 |
| 新增 / 刪除風扇、水排、開孔、溫度計 | 對應分頁的「＋新增」與 ✕ 按鈕 |
| 套用型號 | 「CPU/GPU」分頁的下拉選單 |
| 切換配置 | 畫面下方的 正壓 / 負壓 / 平衡 / 水冷範例 |
| 暫停 / 重置氣流 | 畫面下方按鈕 |

## 🧠 運作原理

- 使用 Jos Stam 的 **Stable Fluids** 方法,在約 110 × N 的格點上求解不可壓縮氣流(對流、壓力投影)
- 風扇以固定速度邊界條件注入 / 抽出氣流,風速由 `風量 ÷ 扇面積` 換算
- 開孔為壓力出口;水排以阻尼多孔介質處理
- 熱源加熱鄰近空氣,熱空氣有浮力;溫度隨對流傳輸,並向室溫衰減(依側板類型)
- CPU / GPU 溫度 ＝ 鄰近空氣溫度 ＋ 功耗 × 等效熱阻(GPU 熱阻隨風扇總風量調整)

## 📚 資料庫說明

選單中的標記代表核對程度:

| 標記 | 意義 |
|---|---|
| ✓ | 已上網核對(顯卡:瓦數與尺寸;CPU:最大功耗 PPT / PL2) |
| ✓W | 只核對瓦數(官方未提供公版尺寸) |
| 無標示 | 典型值或參考設計值,**未逐一核對** |

注意事項:
- 非公版顯卡的尺寸差異很大(例如同一型號長度可相差數十 mm、厚度可差 1–2 槽),**請以實際型號手動修正**
- 風扇口徑與風量為依口徑估算的典型值,多數廠商未公開
- 資料庫可能缺少最新發表的型號,歡迎 PR 補充

資料庫位於 `airflow.html` 內的 `GD`(顯卡)、`CD`(CPU)、`KD`(散熱器)三個物件,格式為逗號分隔字串,可直接編輯新增。

---

## ⚠️ 限制

- 2D 側視模擬,不含三維效應(例如顯卡風扇側向排風、線材與主機板遮擋)
- 發熱量與熱阻為簡化模型,溫度數值僅供比較配置優劣
- 沒有水路與泵浦模型,水冷僅以「熱量轉移到水排」簡化處理
